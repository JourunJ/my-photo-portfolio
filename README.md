
# 个人照片展示集

一个用于记录与展示照片的网站。

## 网站预览

**在线访问：** [个人照片展示集](https://my-photo-portfolio-six.vercel.app/)

## 关于项目

这是我的个人网站，用于整理和展示日常拍摄的照片。

我希望通过这个网站，以独立、简洁的方式保存和展示自己的照片。

## 技术与模板

本网站基于 [Photography Portfolio + Blog — Astro Template](https://github.com/XD-QIN/astro-photo-folio) 构建，并根据个人需求进行了修改与调整。

感谢原作者提供的模板。
